# 模型与评测协议

## 请求、目录与时间

排序样本单位是 `(request_idx, note_idx)`。同一请求内的重复曝光按最大 click 合并，真实曝光未点击取 0。页内位置、query、rec_results、停留和强反馈，以及 notes 表的流行度累计列均不输入模型。物品原始编号加 1，内部 0 专用于 padding；本版本启动时验证目录主键连续、完整且唯一。

官方训练请求先满足「最后一个曝光时间 < 最早官方测试请求时间」。在余下请求的开始时间上取 55%、65%、90% 分位点，顺序划为召回拟合、召回验证、排序拟合、排序验证四个窗口。跨越任何边界的请求整组剔除。验证使用固定时间窗口，测试始终使用同一批官方请求。每个窗口保存请求数、起止时间及有序请求 ID 的 SHA-256。

目录为发布时全部笔记的固定快照。发布物品缺少上线时间和特征版本号；全快照实验描述所发布目录上的离线能力。另在召回拟合期已出现于曝光或近期历史中的 ID 上重建精确索引，报告有此前可见证据的目录实验。这两种口径保留相同测试正例。第一笔可见曝光距今的时间用作物品新鲜度的代理特征，未知值带独立标志。

## 历史与索引

对每个查询按时间回放。只有来自召回拟合或排序拟合、且整组已在该请求开始前结束的请求可以更新用户状态。历史包括这些旧请求的已点击物品及其声明的近期点击快照。快照中物品最晚在旧请求开始时就已被观察，旧请求点击统一延迟到旧请求结束时引入。相同时间戳的事件禁止相互观察。以记录时间为依据，原表没有单独的点击发生时刻。序列按最近已知时间排序，等时按 ID 打破平局，截断至 20。当前请求附带的无逐项时间戳近期列表用于已交互过滤，避免将快照内部推定的顺序当作真实点击时间。测试请求之间不回填任何测试标签。模型权重、全局计数和 ItemCF 均不在测试期更新。

- **Popularity** 在召回拟合期统计带 6 小时半衰期的点击，每次查询使用剩余的衰减权重。
- **ItemCF** 每名用户最多贡献最近 80 个已知物品，12 小时半衰期。由稀疏用户物品矩阵计算加权归一化共现，按用户活跃度降低贡献，每个物品最多 50 个邻居。推理按历史位置的平方根倒数加权聚合。
- **Two-Tower** 物品塔使用拟合期 ID 词表、前两级类目和标题开头最多六个字符二元组的哈希嵌入。冷物品共享 OOV ID 并保留自身内容，训练中随机屏蔽部分 ID。用户塔由用户 ID、掩码均值历史构成，两个塔输出归一化 24 维向量。点击为正例，带温度的批内交叉熵屏蔽重复目标、同请求其他正例和已知历史。其余批内对比项可能含假负例。验证在完整实验候选库上精确检索，按固定验证请求的 Recall@100 选最佳轮次。消融分别去掉用户塔历史、去掉两塔的笔记内容输入，或为每行追加一个经过已交互过滤的真实曝光未点击样本。
- **FAISS / RRF** 主链路采用归一化内积与 IVFFlat，同样的查询另测 FlatIP。Top 100 批量过取并过滤用户见过的物品。三路结果按名次倒数 `sum(1/(60+rank))` 去重融合，平分按内部物品 ID 升序。保存来源位、各路原始排名及分数、融合得分、分组偏移及内部物品 ID。

## 两级排序

LambdaRank 在排序训练期已曝光列表中以真实 request 为 query，输入历史活跃度、历史热度、首见年龄、两级类目匹配、CF 分数、双塔内积和各路召回信息。召回模型与索引在更早的窗口拟合，避免用同一次点击训练召回器再生成该训练行的分数。验证按 NDCG@10 早停，输出保留 RRF Top 100 中的 50 个候选。

MLP 与 DIN 使用相同训练曝光、用户/候选物品嵌入、历史和标准化特征。物品表示包含固定的本项目双塔向量和可训练的 ID 残差。MLP 均值池化历史；DIN 使用目标、历史、差及乘积预测注意力权重，padding 不参与池化，空历史得到零向量。预测头输出 logit，以 BCEWithLogitsLoss 训练，按验证 AUC 选择检查点，推理时从相同 50 个候选中取前 10。概率为 logit 的 sigmoid。

## 指标与解释

召回实验对每个有点击请求计算 Recall、HitRate、NDCG 后宏平均；Catalog Coverage 为至少返回过一次的不同物品数除以该实验目录大小。留存率为命中的唯一请求物品正例数除以全部正例数（微平均）。零点击请求仅进入目录覆盖率和曝光级分类指标。所有截止位使用原请求的完整点击集合，重复点击、过滤掉的已见物品、未被检索到的物品按此口径处理。

曝光列表提供 AUC、NDCG@10、MRR@10、MAP@10 和精排 LogLoss。GAUC 在每个含两类标签的用户内计算，再按该用户参与的曝光数加权，表中同时记录有效用户数。AP@K 的分母为 min(K, 该请求全部正例数)。跨全库链路只衡量已知点击被找回的情况，未曝光项占据排名位置但没有可用于 CTR 的标签。CNN/VLM、外部稠密文本模型、用户画像及未给出时间口径的笔记统计量均未纳入本实验。
